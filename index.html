🔑 Obtenir votre clé API OpenRouter (5 minutes)
1
Créer un compte gratuit — Allez sur openrouter.ai → "Sign Up". Email ou Google, c'est suffisant.
2
Générer une clé API — Dans le tableau de bord, cliquez sur "Keys" → "Create Key". Nommez-la n8n-automation.
3
Copier la clé — Elle commence par sk-or-v1-.... Gardez-la précieusement, elle ne s'affiche qu'une fois.
4
Dans n8n — Créez une credential de type "HTTP Header Auth". Nom du header : Authorization, valeur : Bearer sk-or-v1-VOTRE_CLÉ.
5
Tester — Utilisez le nœud "HTTP Request" dans n8n pour envoyer une requête de test. Si vous recevez une réponse JSON, tout est configuré !
⚙️ Configuration n8n — Copier-Coller
// Nœud : HTTP Request dans n8n URL : https://openrouter.ai/api/v1/chat/completions Méthode : POST Header : Authorization: Bearer sk-or-v1-VOTRE_CLÉ // Body (JSON) : { "model": "mistralai/mistral-7b-instruct:free", "messages": [ { "role": "system", "content": "Tu es un assistant professionnel expert." }, { "role": "user", "content": "{{ $json.prompt }}" } ] } // Réponse : data.choices[0].message.content
💡 Astuce : Pour changer de modèle, modifiez simplement la valeur du champ "model". Tous les modèles listés ci-dessus sont gratuits et fonctionnent avec exactement la même configuration.
