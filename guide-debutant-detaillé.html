📖 Glossaire

Les mots qu'on va utiliser
— expliqués simplement

Avant de commencer, voici tous les termes techniques traduits en français simple. Revenez ici si vous ne comprenez pas un mot.

🙋
Pas besoin de tout mémoriser maintenant. Lisez une fois, puis revenez ici si vous êtes bloqué sur un mot.
🔧 n8n
Un logiciel gratuit qui permet de connecter vos applications entre elles et de leur faire faire des choses automatiquement — comme un chef d'orchestre qui dirige tous vos outils numériques.
🤖 IA (Intelligence Artificielle)
Un programme informatique capable de comprendre le langage humain, lire des documents, rédiger des textes et prendre des décisions — comme avoir un assistant très intelligent disponible 24h/24.
⚡ Workflow (ou automatisation)
Une suite d'actions qui se déclenchent automatiquement sans que vous ayez à les faire manuellement. Exemple : "Quand je reçois un email avec une facture → l'enregistrer dans mon tableau Excel automatiquement".
🌐 API
Un "langage commun" que les logiciels utilisent pour se parler entre eux. Vous n'avez pas besoin de le comprendre en détail — n8n s'en charge pour vous.
🔑 Clé API
Un mot de passe secret et unique qui prouve à un logiciel que c'est bien vous qui l'utilisez. Comme un badge d'accès numérique. À ne jamais partager !
☁️ VPS (Serveur)
Un ordinateur loué sur Internet qui tourne 24h/24 même quand votre PC est éteint. Imaginez un mini-ordinateur que vous louez chez Hostinger pour ~5€/mois et qui travaille pour vous en permanence.
💻 SSH
Un moyen de contrôler un ordinateur à distance via du texte. Vous tapez des commandes dans une fenêtre noire (le "terminal") et l'ordinateur les exécute. Moins compliqué qu'il n'y paraît !
🖥️ Terminal (ou Console)
Une fenêtre avec fond noir où vous tapez des commandes en texte. Sur Windows, c'est "Invite de commandes" ou "PowerShell". Sur Mac, c'est "Terminal". On vous dira exactement quoi taper.
📦 Node.js
Un programme que n8n a besoin pour fonctionner sur votre ordinateur. Imaginez-le comme le "moteur" qui fait tourner n8n. Installation : 2 clics sur le site officiel.
🗂️ JSON
Un format de fichier pour stocker des informations de façon organisée. Les workflows n8n se sauvegardent en JSON — vous n'avez qu'à les importer dans n8n, pas besoin de comprendre le contenu.
🤖 OpenRouter
Un service en ligne qui vous donne accès à plusieurs IA gratuitement. C'est grâce à lui que vos automatisations peuvent utiliser l'IA sans payer d'abonnement mensuel.
🔗 Webhook
Une "sonnette d'entrée" numérique. Quand quelque chose se passe (un email arrive, un formulaire est soumis), le webhook sonne et déclenche votre automatisation.
🖧 localhost:5678
"localhost" signifie "sur mon propre ordinateur". "5678" est le numéro de porte. C'est l'adresse pour accéder à n8n quand il est installé sur votre PC.
📡 Credential (Identifiant)
Dans n8n, c'est l'endroit où vous stockez les mots de passe et clés API de vos services. Vous le configurez une fois, et n8n s'en souvient pour tous vos workflows.

🏗️ Les 3 outils que vous allez utiliser

1
🔧 n8n — Le "chef d'orchestre"
Le logiciel qui connecte tout et exécute vos automatisations
▼

n8n (prononcé "n-eight-n") est un logiciel open source (gratuit et libre) que vous installez soit sur votre ordinateur, soit sur un serveur loué. Son rôle est de :

→
Surveiller ce qui se passe
Il surveille votre boîte email, vos formulaires, votre agenda... et réagit quand quelque chose arrive.
→
Envoyer les données à l'IA
Quand il détecte quelque chose (une facture reçue, par exemple), il envoie les informations à l'IA pour analyse.
→
Effectuer l'action finale
Avec la réponse de l'IA, n8n fait l'action : enregistrer dans Sheets, envoyer un email, créer une tâche...
🎨
n8n a une interface visuelle où vous glissez-déposez des "blocs" pour créer vos automatisations, un peu comme construire avec des pièces de Lego. Pas de code requis !
2
🤖 OpenRouter — L'IA gratuite
Le service qui vous donne accès à l'intelligence artificielle sans payer
▼

OpenRouter est une plateforme qui regroupe des dizaines d'intelligences artificielles. Certaines sont gratuites — et c'est celles-là que vous allez utiliser.

→
Vous créez un compte gratuit
En 2 minutes sur openrouter.ai. Aucune carte bancaire requise pour les modèles gratuits.
→
Vous obtenez une "clé API"
C'est un mot de passe que vous donnez à n8n pour qu'il puisse utiliser l'IA à votre place.
→
L'IA travaille dans vos workflows
n8n envoie du texte à l'IA, l'IA répond, n8n utilise la réponse — tout automatiquement.
✅
Modèles gratuits disponibles : Mistral 7B, Llama 3.1 8B, Gemma 2 9B, Qwen 2.5 7B. Tous très puissants pour les automatisations de ce pack.

Installer n8n
sur votre ordinateur

Cette méthode installe n8n directement sur votre PC ou Mac. Simple, gratuit, mais votre ordinateur doit rester allumé pour que ça marche.

⚠️
À retenir : Tant que votre PC est allumé et connecté à Internet, vos automatisations tournent normalement. Si vous éteignez votre ordinateur ou si Internet coupe, elles s'arrêtent. Pour une solution permanente, utilisez le VPS Hostinger (Section 2B).
1
Installer Node.js — le moteur de n8n
Un logiciel nécessaire pour faire fonctionner n8n
5 minutes
▼

Node.js est un programme informatique dont n8n a besoin pour fonctionner. Vous n'avez pas besoin de savoir ce que c'est — juste l'installer.

1
Ouvrez votre navigateur et allez sur nodejs.org
Tapez nodejs.org dans la barre d'adresse et appuyez sur Entrée.
2
Cliquez sur le bouton vert "LTS" (version recommandée)
Sur la page d'accueil, vous verrez deux boutons verts. Cliquez sur celui qui dit "LTS" ou "Recommended for most users". LTS veut dire "version stable recommandée".
3
Ouvrez le fichier téléchargé et suivez l'installateur
Un fichier .msi (Windows) ou .pkg (Mac) se télécharge. Double-cliquez dessus. Cliquez "Suivant" à chaque étape → "Installer" → laissez faire → "Terminer". Aucune option à changer.
💡
L'installation de Node.js dure environ 2-3 minutes. Ne fermez pas la fenêtre pendant ce temps.
2
Ouvrir le Terminal (la fenêtre noire)
C'est ici que vous taperez les commandes pour lancer n8n
Simple
▼

Le terminal est une fenêtre où vous tapez des commandes en texte. C'est moins effrayant qu'il n'y paraît !

Si vous êtes sur Windows :
Touche ⊞ Windows + R → tapez cmd → Entrée

OU cherchez "Invite de commandes" dans le menu Démarrer et cliquez dessus.

Si vous êtes sur Mac :
Touche ⌘ Cmd + Espace → tapez Terminal → Entrée

Une fenêtre noire (ou blanche sur Mac) s'ouvre avec un curseur clignotant. C'est normal !

3
Lancer n8n avec une seule commande
Copiez et collez cette ligne dans le terminal
3 minutes
▼

Dans la fenêtre noire du terminal, tapez exactement la commande suivante (ou copiez-collez-la) :

Terminal / Invite de commandes
C:\Users\VotreNom>
npx n8n

# Attendez... n8n se télécharge et s'installe
Need to install the following packages:
n8n@1.x.x
Ok to proceed? (y)
# Appuyez sur la touche Y puis Entrée

✔ n8n ready on http://localhost:5678
# ← Quand vous voyez ça, c'est bon !
_
⚠️
Si le terminal vous demande "Ok to proceed? (y)" → tapez la lettre y et appuyez sur Entrée. Ne fermez PAS cette fenêtre noire pendant l'utilisation de n8n — c'est elle qui fait tourner le logiciel.

Acheter un VPS sur Hostinger

L'adresse IP ressemble à : 185.234.XX.XX. C'est l'adresse de votre mini-ordinateur sur Internet. Notez-la bien.
2
Se connecter au serveur via SSH
Prendre le contrôle de votre mini-ordinateur à distance
5 minutes
▼

SSH vous permet de contrôler votre serveur Hostinger depuis votre PC, comme si vous tapiez sur son clavier à distance.

Sur Windows :
⊞ Windows → tapez PowerShell → Clic droit → Exécuter en tant qu'admin
Sur Mac :
⌘ Cmd + Espace → tapez Terminal → Entrée

Dans la fenêtre ouverte, tapez cette commande (remplacez l'IP par la vôtre) :

Terminal — Connexion SSH
$
ssh root@185.234.XX.XX
# Remplacez 185.234.XX.XX par votre vraie adresse IP

Are you sure you want to continue connecting? (yes/no)
# Tapez : yes puis Entrée

root@185.234.XX.XX's password:
# Tapez votre mot de passe Hostinger (rien ne s'affiche, c'est normal !)

Welcome to Ubuntu 22.04 LTS
root@vps:~#
# Vous êtes connecté ! Le curseur attend vos commandes.
⚠️
Quand vous tapez votre mot de passe SSH, rien ne s'affiche à l'écran — ni étoiles, ni points. C'est normal, c'est une mesure de sécurité. Tapez votre mot de passe en aveugle et appuyez sur Entrée.

Installer n8n sur le serveur
3 commandes et c'est fait — copiez-collez simplement
10 minutes
▼

Une fois connecté à votre serveur (vous voyez root@vps:~#), tapez ces commandes une par une. Appuyez sur Entrée après chaque ligne et attendez que ça se termine :

Serveur Hostinger — Installation n8n
# Commande 1 : Mettre à jour le serveur (attendez ~2 min)
root@vps:~#
apt update && apt upgrade -y

# Commande 2 : Installer Node.js (attendez ~1 min)
root@vps:~#

💡
Ces commandes peuvent afficher beaucoup de texte qui défile — c'est normal ! Attendez simplement que le curseur root@vps:~# réapparaisse pour savoir qu'une commande est terminée.

Lancer n8n en mode permanent
Démarrer n8n pour qu'il tourne indéfiniment
3 minutes
▼

Pour que n8n tourne même si vous fermez le terminal, on utilise un outil appelé "screen" qui maintient le processus en vie :

Démarrage de n8n en arrière-plan

root@vps:~#
apt install -y screen

# Créer une session screen nommée "n8n"
root@vps:~#
screen -S n8n

# Une nouvelle fenêtre s'ouvre. Lancez n8n dedans :
root@vps:~#
N8N_BASIC_AUTH_ACTIVE=true N8N_BASIC_AUTH_USER=admin N8N_BASIC_AUTH_PASSWORD=VotreMotDePasse n8n start

Editor is now accessible via:
http://0.0.0.0:5678/
# Pour quitter screen sans arrêter n8n : Ctrl+A puis D
⚠️
Remplacez VotreMotDePasse par un mot de passe de votre choix. Notez-le car c'est ce que vous utiliserez pour vous connecter à n8n depuis votre navigateur.
💡
Pour détacher screen sans arrêter n8n : Appuyez simultanément sur Ctrl+A puis relâchez et appuyez sur D. n8n continue de tourner en arrière-plan !

Configurer l'IA dans n8n
et lancer votre 1er test

Maintenant que n8n est installé, on connecte votre clé OpenRouter pour que l'IA fonctionne dans vos workflows.

1
Ajouter votre clé OpenRouter dans n8n
Connecter l'IA gratuite à votre instance n8n
5 minutes
▼

Dans l'interface n8n (ouverte dans votre navigateur), suivez ce chemin :

Dans n8n → ⚙️ Settings → Credentials → + Add Credential
1
Cherchez "HTTP Header Auth" dans la liste
Une fenêtre de recherche s'ouvre. Tapez "Header" et sélectionnez "Header Auth" ou "HTTP Header Auth".
2
Remplissez le formulaire
• Name : OpenRouter-Free
• Name (header) : Authorization
• Value : Bearer sk-or-v1-VOTRE_CLÉ_ICI
(Remplacez VOTRE_CLÉ_ICI par la clé que vous avez copiée depuis OpenRouter)
3
Cliquez "Save"
Cliquez le bouton bleu "Save" ou "Créer". Votre identifiant OpenRouter est maintenant sauvegardé dans n8n.
2
Tester l'IA avec un workflow simple
Vérifier que tout fonctionne en 2 minutes
5 minutes
▼

Créons un workflow test ultra-simple : vous cliquez un bouton → l'IA répond "Bonjour !"

1
Créez un nouveau workflow
Dans n8n, cliquez sur "+ New Workflow" ou le bouton pour créer un nouveau workflow.
2
Ajoutez un nœud "Manual Trigger"
Cliquez sur le bouton "+" pour ajouter un nœud. Cherchez "Manual Trigger" et sélectionnez-le. C'est le bouton de déclenchement manuel.
3
Ajoutez un nœud "HTTP Request"
Cliquez encore sur "+" → cherchez "HTTP Request" → sélectionnez-le → connectez-le au Manual Trigger.
4
Configurez le nœud HTTP Request
• Method : POST
• URL : https://openrouter.ai/api/v1/chat/completions
• Authentication : Predefined Credential → sélectionnez "OpenRouter-Free"
• Body : JSON — collez le code ci-dessous
Corps de la requête (Body) — À copier-coller
{ "model": "mistralai/mistral-7b-instruct:free", "messages": [ { "role": "user", "content": "Dis-moi juste Bonjour en français !" } ] }
5
Cliquez "Execute Workflow" et regardez le résultat !
Cliquez le bouton "Execute Workflow" en bas. Les blocs vont s'animer et vous verrez la réponse de l'IA apparaître en vert sur le nœud HTTP Request. Si vous voyez une réponse "Bonjour !" → tout fonctionne parfaitement !
🎉
Si vous voyez une réponse de l'IA, félicitations ! Votre configuration est complète. Vous pouvez maintenant importer et utiliser tous les workflows de ce pack.
